# Overview #

If you use the Smartlife App to manage your Tuya zigbee based Home Automation you will notice that the timer based functions fail when your internet is down.

This isn't an issue when you use a third party Application Like HomeAssist, which manages all your devices directly. However I wanted to understand how the device network hung together, and as an avid PHP user, I decided I would try to implement a PHP timer solution to control devices on my local network without Cloud based services.
